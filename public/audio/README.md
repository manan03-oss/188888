# Optional music

The site works without music. To add a song, use only a recording you have the
right to use (for example one you own or have a licence for).

1. Name it exactly `anniversary-music.mp3`.
2. Put it in this folder (`public/audio/`), replacing nothing else.
3. Rebuild/redeploy. Music only starts when Shreya presses play.

To use a different file name, change `musicSrc` in `src/data/anniversaryContent.ts`.
